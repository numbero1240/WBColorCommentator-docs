# WBColorCommentator — 設計と開発の記録

Shadowverse: Worlds Beyond の**終了済みの対戦の録画**から、ターンごとの最善手とその根拠を出す個人用の分析ツールの、
方針・設計書・開発日誌を公開しているリポジトリです。

ツール本体のコードは公開していません。理由は [POLICY.md](POLICY.md) に書いています。

- [POLICY.md](POLICY.md)：利用規約への対応方針（対戦中には使えない設計にしていること、など）
- [DESIGN.md](DESIGN.md)：設計書
- [devlog/](devlog/)：開発日誌
